# Automated System for Recording Hostel Students’ Arrivals and Departures

## 📌 Project Overview
This is a group academic project developed for NSBM Green University.  
The project is a Windows-based desktop application designed to automate the manual hostel student movement recording system.

The system enables the hostel warden to efficiently record student arrivals, departures, short leaves, and emergency situations, while automatically notifying parents via email.



## 🎯 Objectives
- Automate hostel student movement tracking  
- Reduce manual record-keeping errors  
- Improve communication with parents  
- Enhance hostel security and transparency  



## 👥 Target Users
- Hostel Warden (Administrator)



## ✨ Key Features
- Secure login system  
- Student and parent registration  
- Arrival and departure logging with date & time  
- Automated email compose notifications to parents  
- Short leave management  
- Emergency contact handling  
- Dashboard with daily statistics  
- Input validation and error handling  
- User-friendly Windows Forms interface  



## 🛠️ Technologies Used
- Programming Language:C#  
- Framework: .NET Windows Forms  
- Database: Microsoft Access (ACCDB)  
- Data Access: OleDb  
- Email Integration: `mailto:` using `Process.Start()`  
- IDE: Visual Studio  



## 🧱 System Architecture
- Single-user desktop application  
- Modular Windows Forms design  
- Local MS Access database  
- Event-driven programming model  



## 🗂️ Database Tables
- Students  
- Parents  
- StudentMovement  
- ShortLeave  
- EmergencyLeave  
- LoginCredentials
